# Get count of elements that were returned from JSON data query

This will return the no of elements that were returned from JSON data
query.

## Usage

``` r
get_count(x)
```

## Arguments

- x:

  a list, i.e. a JSON data object

## Value

no_elements an integer, no of elements to download a value between 1 to
100

## Examples

``` r
if (FALSE) { # \dontrun{
###Return no of elements from a JSON data object (obtained using get_JSON_doc())
get_count(x = JSON_doc)
} # }
```
