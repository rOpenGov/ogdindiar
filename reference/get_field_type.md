# Get field/variable types from the JSON data object

This will return field types from the JSON data object.

## Usage

``` r
get_field_type(x)
```

## Arguments

- x:

  a list, i.e. a JSON data object

## Value

field_types a list/vector, field type of each of the fields

``` r
if (FALSE) { # \dontrun{
```
